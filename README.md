## Описание

Интеграция для управления умной светодиодной лампой-матрицей от Алекса Гайвера через протокол MQTT.

Лампа поддерживает 26 эффектов, регулировку яркости, скорости и масштаба эффектов.

## Установка

### Способ 1: Установка через HACS (рекомендуется)

1. Откройте HACS → Интеграции
2. Нажмите на три точки в правом верхнем углу → "Добавить репозиторий"
3. Вставьте ссылку: `https://github.com/shaman1641/Gyver_lamp_hasio`
4. Найдите "Gyver Lamp MQTT" в списке интеграций и нажмите "Установить"
5. Перезагрузите Home Assistant
6. Перейдите в Настройки → Устройства и службы → Интеграции → Добавить интеграцию
7. Найдите "Gyver Lamp MQTT" и следуйте инструкциям

### Способ 2: Ручная установка

1. Скачайте репозиторий
2. Скопируйте папку `custom_components/gyver_lamp` в `/config/custom_components/` вашего Home Assistant
3. Перезагрузите сервер
4. Добавьте интеграцию через интерфейс

## Настройка

При добавлении интеграции укажите:

| Параметр | Описание | Пример |
|----------|----------|--------|
| **Имя лампы** | Произвольное имя для устройства | `Лампа в спальне` |
| **Топик команд** | Топик для отправки команд лампе | `LedLamp/LedLamp_1a2b3c4d/cmnd` |
| **Топик состояния** | Топик для получения состояния лампы | `LedLamp/LedLamp_1a2b3c4d/state` |

### Как узнать топики вашей лампы

1. Включите лампу
2. В интерфейсе лампы найдите раздел о подключении к сети / информация о устройстве
3. Скопируйте значения топиков (или посмотрите в логах подключения лампы к брокеру)


### Основной свет (Сущность: `light.*`)

- **Включение/выключение** — переключает матрицу лампы
- **Яркость** — регулируется ползунком в %
- **Цвет** — регулируется кругом, иноглда круг регулирует масштаб
- **Скорость** — регулируется ползунком теплоты цвета (в режиме белого свечения регулирует теплоту)
- **Эффекты** — 26 эффектов на выбор:
  - Конфетти, Огонь, Белый огонь
  - Радуга (верт./гориз./диаг./3D), Павлин 3D
  - Облака 3D, Лава 3D, Плазма 3D
  - Зебра 3D, Лес 3D, Океан 3D
  - Смена цвета, Цвет, Белый свет
  - Снегопад, Метель, Звездопад
  - Матрица, Светлячки, Светлячки шлейф
  - Пейнтбол, Кубик, Безумие 3D




### Включение лампы на 50% яркости с эффектом "Звездопад"

```yaml
alias: Включить лампу на ночь
trigger:
  - platform: time
    at: "23:00:00"
action:
  - service: light.turn_on
    target:
      entity_id: light.gyver_lamp
    data:
      brightness_pct: 50
      effect: "Звездопад"
